# Day 11 Reflection – Salesforce API Integration

## What I Learned

Day 11 helped me understand how Salesforce communicates with external systems through REST APIs.

I learned how to configure an External Credential, External Credential Principal, Permission Set, and Named Credential. I also learned how these components work together to provide secure access to an external API.

I learned that Apex can perform HTTP callouts and that Queueable Apex can be used when the integration needs to run asynchronously.
