# Day 9 – Reflection

## What I Learned

Day 9 helped me understand how a Salesforce application can be designed from the user's perspective.

I learned that an LWC should represent a meaningful user capability rather than simply being created because the technology is being learned.

I implemented an Eligible Jobs component that allows students to:

- View available jobs.
- View important job information.
- View additional job details.
- Apply for a job.

## Technical Learning

I practiced:

- Lightning Web Components
- HTML templates
- JavaScript event handling
- Conditional rendering
- Apex classes
- SOQL
- Salesforce custom objects
- Application records
- Toast notifications
- Modal-based UI

## Challenges

One challenge was connecting the buttons and modal behaviour correctly. I also had to make sure that the job details displayed correctly when a particular job was selected.

Another important part was understanding how the Student, Job, and Application records are related.

## What I Improved

I improved my understanding of separating the user interface from Salesforce backend functionality.

I also learned that after a user action changes data, the UI should remain consistent with the underlying Salesforce data.

## Final Reflection

This task showed me how the different Salesforce concepts learned in previous sessions can come together to create a practical Placement Management System.

Instead of only working with individual Salesforce features, I was able to build a user-facing workflow for viewing jobs and applying for opportunities.
