# Block 4: Lightning Web Components (LWC)

## Objective

The objective of this task was to understand the fundamentals of Lightning Web Components (LWC) and build a simple reusable component to display records from a custom Salesforce object using the `@wire` decorator.

## Scenario

Using the **Hospital OPD Management System** developed in the previous blocks, I created a Lightning Web Component to retrieve and display records from a custom object in the Salesforce Lightning Experience.

## Tasks Performed

* Learned the basics of Lightning Web Components (LWC).
* Created a new Lightning Web Component.
* Used the `@wire` decorator to retrieve data from Salesforce.
* Displayed records from a custom object in the component.
* Added the component to a Lightning Home Page using Lightning App Builder.
* Verified that the component displayed real data successfully.

## Expected Outcome

The Lightning Web Component was successfully deployed and displayed custom object records on the Home Page without any errors. The component was tested in the Salesforce Trailhead Playground.

* Lightning Web Component source files

* LWC deployment files

## Key Concepts Learned

* Lightning Web Components (LWC)
* Component Structure
* `@wire` Decorator
* Salesforce Data Retrieval
* Lightning App Builder
* Component Deployment

## Learning Outcome

This activity introduced me to Salesforce's modern UI development framework. I learned how to build reusable Lightning Web Components, retrieve Salesforce data using the `@wire` decorator, and display the component on a Lightning page. This provided a strong foundation for building interactive Salesforce applications.
