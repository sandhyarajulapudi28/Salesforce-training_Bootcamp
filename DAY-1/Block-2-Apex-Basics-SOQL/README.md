# Block 2: Apex Basics – Classes, Variables & SOQL

## Objective

The objective of this block was to learn the fundamentals of Apex programming, understand basic programming concepts in Salesforce, and practice retrieving data using Salesforce Object Query Language (SOQL).

## Tasks Performed

### Apex Basics

* Practiced Apex syntax by writing code in the Execute Anonymous window.
* Declared variables and used different data types.
* Created basic Apex classes and methods.
* Executed code using the Developer Console.
* Verified the execution results by reviewing the Debug Log.

### SOQL Practice

Using the Hospital OPD data model created in Block 1, I wrote and executed the following SOQL queries:

1. WHERE clause query
2. ORDER BY with LIMIT
3. Relationship query (Child-to-Parent / Parent-to-Child)
4. Aggregate query using COUNT()
5. Comparison query using the `>=` operator on a date or numeric field

All queries executed successfully without syntax errors, and the outputs were saved for documentation.

## Expected Outcome

Successfully executed Apex code in the Developer Console and validated the results using the Debug Log. Completed five SOQL queries to retrieve and analyze records from the custom Hospital OPD objects.

## Key Concepts Learned

* Apex Classes
* Variables and Data Types
* Methods
* Execute Anonymous
* Developer Console
* Debug Logs
* SOQL Syntax
* WHERE Clause
* ORDER BY
* LIMIT
* Relationship Queries
* Aggregate Functions
* Comparison Operators

## Learning Outcome

This activity strengthened my understanding of Apex programming and database querying in Salesforce. I learned how to write and execute Apex code, interpret Debug Logs, and use SOQL to efficiently retrieve, filter, sort, and summarize data from custom objects.
