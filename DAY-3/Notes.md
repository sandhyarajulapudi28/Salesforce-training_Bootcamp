# Day 03 Notes

## Scenario

Placement Management System

### Objects

- Student
- Job
- Job Application
- Offer Letter
- Placement Officer

---

## Automation Implemented

- Automatically populate Application Date.
- Prevent duplicate job applications.
- Reject applications below the required CGPA.
- Send email notification to Placement Officer.
- Automatically create an Offer Letter when a student is selected.

---

## Key Concepts

- Validation Rules
- Record-Triggered Flow
- Before Save Flow
- After Save Flow
- Flow Builder
- Email Action
- Formula Validation
- Order of Execution

---

## Best Practices

- Use Flow for declarative automation.
- Use Validation Rules for data quality.
- Use Apex only for complex business logic.
- Avoid duplicate automation.
- Keep Flows simple and reusable.
