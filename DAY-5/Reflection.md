# Day 5 Reflection

Today, I learned how business logic is implemented in Salesforce using Apex.

I created an Apex class named `ApplicationService` and implemented the `submitApplication()` method to process student job applications.

I understood the importance of validating business rules before saving records. I implemented duplicate application checking and CGPA validation using SOQL queries and conditional statements.

I also learned how to use DML operations to insert records and tested the functionality using the Execute Anonymous Window in the Developer Console.

Overall, this session helped me understand how Apex enables Salesforce applications to make business decisions rather than simply storing data.
