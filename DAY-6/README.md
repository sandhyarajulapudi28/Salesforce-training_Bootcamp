# Day-6: Making Software Talk to Data with SOQL and DML

## Objective
Learn how Apex interacts with Salesforce data using SOQL and DML operations.

## What I Built
- Created Apex classes for SOQL and DML examples.
- Retrieved Student records using SOQL.
- Updated Student records using DML.
- Executed Apex code using Execute Anonymous.
- Verified the results through Debug Logs and Salesforce records.

## SOQL
SOQL (Salesforce Object Query Language) is used to retrieve records from Salesforce objects.

## DML
DML (Data Manipulation Language) is used to create, update, and delete Salesforce records.

## What I Learned
- How to retrieve records using SOQL.
- How to update records using DML.
- How Execute Anonymous helps test Apex code.
- Importance of querying data before making business decisions.
- Importance of verifying changes using Debug Logs.
