# Reflection

## What I Learned

During this assignment, I learned how Salesforce executes asynchronous operations using different Apex mechanisms.

I implemented:

- Future Method
- Queueable Apex
- Batch Apex
- Scheduled Apex

I also learned how to test these implementations using Anonymous Apex and verify execution through Apex Jobs and Scheduled Jobs.

## Challenges Faced

- Configuring the Salesforce CLI.
- Deploying Apex classes from Visual Studio Code.
- Resolving deployment errors.
- Understanding constructors in Queueable Apex.
- Testing asynchronous execution correctly.

## How I Solved Them

I corrected deployment issues, deployed the Apex classes successfully, executed each asynchronous process using Anonymous Apex, and verified the results through Salesforce Setup.

## Outcome

This assignment strengthened my understanding of Salesforce Asynchronous Apex and improved my practical knowledge of deployment, testing, and debugging using Visual Studio Code and Salesforce CLI.
