# Block 1: Apex Collections (List, Set, Map)

## Objective

The objective of this task was to understand Apex Collections and learn how to efficiently store, retrieve, and manipulate data using Lists, Sets, and Maps.

## Tasks Performed

### List Collection
- Created a `List<String>` containing five city names.
- Iterated through the list using a loop.
- Displayed each city name in uppercase using the Debug Log.

### Set Collection
- Queried records from the custom Hospital OPD object.
- Stored record Ids in a `Set<Id>` to eliminate duplicate values.
- Verified the number of unique records using the `size()` method.

### Map Collection
- Queried custom object records into a `Map<Id, YourObject__c>`.
- Retrieved a record using its Id.
- Displayed a field value from the retrieved record in the Debug Log.

## Expected Outcome

Successfully executed all collection examples and verified the output in the Developer Console Debug Log.

## Key Concepts Learned

- List Collection
- Set Collection
- Map Collection
- SOQL with Collections
- Iteration
- Data Retrieval
- Debug Logs

## Learning Outcome

This activity improved my understanding of Apex Collections and their practical use in Salesforce development. I learned how Lists maintain order, Sets prevent duplicate values, and Maps provide efficient record retrieval using unique keys.
