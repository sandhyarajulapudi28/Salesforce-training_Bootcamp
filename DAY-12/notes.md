\## 1. Git and Version Control



Git is used to maintain the history of the project and support collaboration between developers.



\### Important Git Concepts



\- Repository – stores the project and its history.

\- Clone – downloads a repository to the local machine.

\- Commit – records a logical change locally.

\- Push – sends local commits to the remote repository.

\- Pull – brings changes from the remote repository.

\- Branch – provides an isolated place to develop changes.

\- Pull Request – allows changes to be reviewed before merging.

\- Merge Conflict – occurs when Git cannot automatically combine changes.
