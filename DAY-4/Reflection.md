# Day 4 Reflection – Lightning Web Components (LWC)

Today, I built my first Lightning Web Component (LWC) for the Placement Management System. I learned how HTML, JavaScript, CSS, and the Meta XML file work together to create a user interface in Salesforce.

I created a Placement Home page with a welcome banner, student profile, current date, dashboard cards, and interactive buttons. I also implemented data binding and JavaScript event handling to display welcome messages and update the application status.

This activity helped me understand how the frontend of a Salesforce application is built and prepared me for connecting LWC with Apex in the upcoming sessions.
